# Design the CLI for humans and agents

Paclang applies the AXI principles to the whole CLI rather than only to TOON output. One typed report model feeds `terminal`, `toon`, `json`, and `markdown` formats. JSON is the durable interchange contract. TOON is the default redirected format but declares its working-draft specification version separately from the report schema version. A TTY selects `terminal`; an explicit `--format` overrides detection. Large lists include totals and truncate to ten rows by default, with `--limit`, `--top`, `--full`, and `--fields` controls. Rows sort by metric descending and canonical name ascending. Structured output carries integer numerators and denominators, while human percentages use deterministic rounding that totals 100.0%. Reports never prompt, empty results are explicit, and structured errors use exit code 1 for runtime failures and exit code 2 for invalid CLI use. An optional agent skill documents the interface, and `paclang status --format toon` provides on-demand context. Paclang does not install session hooks or modify agent configuration automatically.
