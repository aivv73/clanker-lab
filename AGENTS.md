## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues for `aivv73/clanker-lab`. See `docs/agents/issue-tracker.md`.

### Domain docs

This repo uses the single-context domain-doc layout. See `docs/agents/domain.md`.

### Linked Specs

This project uses the Linked Specs convention; consult the `linked-specs`
skill before working with specs or governed code.

### Reviews

After substantial changes, use the `dpc-general-multipart-review` skill with
an independent coordinating reviewer who did not create or modify the change.
